# Benchmark problems

`sezgi.problems.*`: CEC 2014/2017/2022, TSPLIB, and a small diagnostic
trio (onemax / int_quadratic / cat_match) plus a mixed-space scaffold.
Every handle here is `solve()`-eligible, exactly like `sezgi.bbob(...)`.
